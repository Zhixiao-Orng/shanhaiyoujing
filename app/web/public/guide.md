# 见全局·山海有径使用指南

适用范围：【见全局·山海有径】 v0.1.0 本地部署版（工程标识 Task Atlas / task-atlas）。使用前请按项目安装说明完成安装并启动服务。

## 1. 这是什么

【见全局·山海有径】是一款长线任务管理工具，帮助你在推进一项长期工作时，始终看见总目标、各阶段和当前分支。一个“项目”可包含一个或多个总目标；总目标下面可分阶段，阶段下面可继续分子任务。图谱与任务详情共用同一份本地数据。

它在 Codex 的**右侧浏览面板**呈现，像其他在右侧打开的产物一样，需要打开相应面板才能看见。它不是永久固定的原生侧栏。关闭面板不会删除任务，下次重新打开即可。完成插件安装并启用后，无须每次重新安装。若当前客户端不支持右侧浏览面板，也可以在浏览器中打开服务提供的地址。

支持 Codex 和 WorkBuddy。两者均可通过配套技能协作，页面呈现方式以客户端能力为准；下文涉及 Codex 右侧面板的操作特指 Codex，其他情况下可在浏览器打开本机看板。

## 2. 第一次使用：把计划放进图谱

在有该计划内容的 Codex 对话中发送：

> 使用【见全局·山海有径】。先核对本对话已经确定的总目标、阶段和实际进度；检查是否已有对应项目，避免重复创建。然后把计划加入图谱，并在右侧打开。

如果对话里尚未定稿，可以先讨论目标、各阶段及完成标准，再发这条指令。阶段数量按实际工作决定，不固定为六个。Codex 应核对已有任务；拿不准的进度保留为待安排或待确认，不能凭推测标成已完成。

如果安装包包含演示项目，演示数据仅用于体验功能，不代表实际工作进度。开始正式使用时，请创建自己的项目，并使用容易识别的名称。

## 3. 日常怎么看

| 位置 | 用法 |
|---|---|
| 项目菜单 | 在不同长期工作之间切换。 |
| “1.总目标” | 位于“看见全局”模块；查看总目标、进度和主阶段，点击阶段可切换当前聚焦。它随页面正常滚动，不会固定遮挡导图。 |
| 导图画布 | 单击任务节点查看它；在画布内用触控板双指向任意方向滑动可平移导图，单指按住拖动只用于调整任务所属分支，拖动空白处不会平移画布；触控板双指捏合用于缩放，点击节点上的“折叠”可收起子任务。 |
| “查看全图” | 把整棵任务树放回画布视野。 |
| “定位当前” | 放大到当前聚焦的任务。 |
| “2.任务状态” | 查看从总目标到当前任务的路径、说明和状态；点击“编辑详情与子任务”进入详细页面。 |
| “3.新想法”与想法池 | 手动暂存发散方向，不计入主线进度；需要执行时可把想法拖到导图节点，或先放入导图再决定位置。 |

图中的**实线**表示主任务和子任务，例如“第二阶段包含两项行动”；节点上的“前置／后续”角标表示依赖关系，鼠标悬停即可查看相关任务名称，不再通过虚线连接。单击节点只改变查看焦点，不会自动开始执行，也不会更改状态。

顶部进度按本目标下**未取消的末级任务**计数。例如“3 / 7”表示七个末级任务中有三个被标为已完成，不表示已花或还需多少时间。想法池不计入进度。

## 4. 怎么推进和更新状态

已加入主线的任务也能调整位置：按住导图中的任务标题或卡片，把它拖到另一个任务节点上松手，即可移入该节点下面，原有子任务会保留。拖到空白处会恢复原来的结构位置；总目标根节点不参与这种移动。

直接点击导图节点上的状态文字（如“进行中”），即可选择新状态。也可以点击任务节点，再使用下方“2.任务状态”中的下拉框。选择状态后，页面会保存；也可以在对应的 Codex 对话中说明进度，让 Codex 更新同一项目。

| 状态 | 适用时机 |
|---|---|
| 待安排 | 先记录，还未确定什么时候做。 |
| 待办 | 已确定要做，但尚未开始。 |
| 进行中 | 正在推进。 |
| 待验收 | 已有结果，等待检查。 |
| 受阻 | 因材料、权限或其他条件暂时无法推进。 |
| 已完成 | 结果得到确认。 |
| 已取消 | 决定不再做。 |

推荐在开始阶段时设为“进行中”，形成结果后设为“待验收”，确认完成后再设为“已完成”。图谱不会根据聊天内容自行判断某一步已经完成；需要你或加载技能的 Codex 对话明确更新。

## 5. 怎么使用想法池

### 直接在面板中添加

滚动到“3.新想法”，点击“添加想法”，输入标题，按需填写说明，再点“保存到想法池”。保存后可展开列表，点击某条想法查看详情。它不会自动变成主计划的一步。

### 直接拖入导图

展开想法池，按住想法卡片，把它拖到导图里的某个任务节点上，稍作停留后松手。它会成为该节点的子任务，因此可以直接放到总目标、某个主阶段或更深的子任务下。拖到画布空白处时，它只会变成“待放置”节点，尚未加入主线。

### 先放入导图再调整

点击想法右侧的“加入任务”，它会作为虚线边框的“待放置”节点出现在导图中。按住这个节点，拖到目标任务节点上松手，即可作为该任务的子任务；拖动时目标节点会高亮。放置前它仍留在想法池，也不计入主线进度。导图上方还可点击“设为独立总目标”或“取消放置”。如果项目还没有总目标，点击“加入任务”也只会生成待放置节点，再点击“设为独立总目标”建立第一个总目标。

完成放置后，原想法会从想法池移入所选分支的末尾，保留标题、说明和状态；总目标展示、导图连接线和任务路径会同步更新。

### 在 Codex 对话中收集

在已确定项目归属、并加载【见全局·山海有径】技能的对话里，你提出明确的新设想或以后可发展的方向时，Codex 应检查是否已有同类记录，保存后简短告知。普通提问、被否定的设想、助手自己提出而你未采纳的建议，不应被当作你的想法收藏。需要立即执行的工作应按正常任务处理，不重复放入想法池。

这项对话收集依赖模型在**当前对话中执行技能**。它不在后台读取所有 Codex 聊天，也不因浏览器里开着某个演示项目就把想法写到该项目。项目归属不明确时，Codex 应先确认。自动触发已写入技能规则，但跨多个真实对话的效果仍需在使用中验证。

## 6. 新对话和旧对话怎样启用

新对话中可以说：

> 使用【见全局·山海有径】，打开“我的项目名称”，接着推进。

已经进行过的旧对话可以继续使用原有上下文。若它没有识别到新版插件，可明确说：

> 请读取当前环境中已安装的 Task Atlas（【见全局·山海有径】）技能，先核对本对话的原计划和现有项目，再同步进度并在右侧打开图谱。

如果仍未识别到技能，请从自己的插件安装目录中找到 `SKILL.md`，将实际路径提供给 Codex。不同电脑的安装位置可能不同。

对话负责把计划或更新写入项目；右侧面板负责展示和手动编辑。插件启用不等于每次切换对话都自动弹出面板。需要查看时说“打开这个项目的【见全局·山海有径】”，或切回已打开的右侧面板。

## 7. 编辑任务、标签和工作日志

在导图点击一个任务，再点击“编辑详情与子任务”。属性区顶部的“标题”可以修改任务名称；这里还可调整状态、优先级、负责人和截止日期。工作流、开发上下文和重复的操作入口已移除。

### 添加标签

点击属性中的“标签”，在搜索框输入名称；如果还没有这个标签，点击“创建”即可。点击已有标签名称可添加到当前任务，再次点击可取消当前任务上的该标签。

### 选择颜色

在标签列表中，点击名称左侧的小色块，打开选色面板。点击一种常用颜色即可保存并返回列表；也可以点击“自定义颜色”的色块选择颜色，然后点击“返回标签”。新建标签默认灰色，创建后按同样方式改色。点击色块只修改颜色，不会选中或取消标签。

颜色按标签名称保存在当前浏览器中，同名标签共用颜色；刷新页面后仍保留。换浏览器或清除浏览器数据后需要重新设置，颜色不随任务数据库备份迁移。

### 删除不用的标签

点击标签右侧垃圾桶，再点击确认区的“删除标签”。这会从本项目所有任务（包括已归档任务）中移除该标签，不会删除任务。默认标签的隐藏设置保存在当前浏览器中；与只取消当前任务上的标签不同，删除的影响范围是整个项目。

### 记录工作日志

在属性区的“工作日志”输入推进情况、注意事项或下一步安排，再点击“添加记录”。保存后显示记录时间，较新的记录排在上面；刷新或重新打开任务仍可查看。日志是记录，不会自动改变任务状态或进度。目前此区域不提供修改、删除已有日志的按钮。

### 关系

“阻塞于”表示当前任务需要等待另一个任务；“阻塞”表示当前任务会挡住另一个任务；“相关议题”表示两项工作有关联，但不表示先后顺序。主任务和子任务表示包含关系，与阻塞关系不同；设置关系不会自动执行任务。

## 8. 在 Codex 或 WorkBuddy 中协作

看板用于展示和管理任务。需要 AI 协助规划、更新进度或收集想法时，请在已加载【见全局·山海有径】技能的 Codex 或 WorkBuddy 对话中操作。看板不提供独立 AI 聊天入口。看板数据库保存在本机，不提供云端同步；但交给 AI 对话处理的内容可能发送到对应 AI 服务，不能理解为整个协作过程完全离线。

## 9. 数据、重启与边界

默认本地部署将任务保存在项目目录下的 SQLite 数据库 `app/.data/taskboard.sqlite`。如果部署时设置了其他数据目录，以实际配置为准。折叠和当前聚焦位置保存在打开面板的浏览器本地。项目数据不会因为关闭右侧面板而消失；但服务关闭时，页面暂时无法加载。

安装【见全局·山海有径】技能后，可以在 Codex 中要求“打开【见全局·山海有径】”，由技能按需启动本地服务。也可以在终端进入 Task Atlas 的安装目录（包含 `scripts` 和 `app` 的目录），执行：

```sh
python3 scripts/atlas.py start
```

随附启动脚本默认使用 `http://127.0.0.1:47823`，该地址只在运行服务的电脑上有效。其他部署方式以实际服务地址为准；是否开机启动取决于用户的部署配置。备份前先停止服务，再复制实际数据目录（默认 `app/.data`）；不要直接删除数据目录。演示项目不能代替正式数据备份。

同步计划时，技能使用稳定标识避免重复创建；缺少状态字段时会保留页面里已有的状态，也不会因为计划文本未提到某任务就自动删除它。若计划结构发生重大调整，应在对话中说明要保留、合并或取消哪些节点。

## 10. 常见问题

### 看不到面板

插件安装与面板显示是两件事。让 Codex“打开某项目的【见全局·山海有径】”；如果本机服务没有运行，也请它启动服务后再打开。

### 进度没有变化

检查具体末级任务是否设为“已完成”，以及是否处在正确的项目和总目标下。只写“已经做了”但未同步状态，不一定改变进度。

### 想法没自动出现

确认当前对话已加载【见全局·山海有径】技能、已明确项目归属，并检查 Codex 是否告知保存成功。可以直接使用面板上的“添加想法”。

### 旧对话没有识别插件

按第 6 节要求读取已安装技能，必要时提供自己的实际安装路径，不必重新开始原来的工作。

### 需要改回原有任务细节

点击节点后选择“编辑详情与子任务”。


## 11. 版本更新与使用指南

点击看板右上角的“使用指南”，会在当前面板打开独立的指南网页。点击左上角 Menu 展开大纲，选择章节即可跳到正文位置；全文可以连续滚动。右上角提供搜索和深色／浅色切换，主题选择会保存在当前浏览器中。点击右上角“返回看板”可回到原项目；查看指南不会修改任务。

看板每 30 秒检查一次版本，重新切回窗口时也会检查。发现尚未确认的版本后，弹窗列出版本号和更新内容。点击“更新”会刷新当前页面；点击“此次忽略”只关闭本次提示，下次进入还会提示。检测到编辑过且仍保留的输入内容时，刷新前会提醒你先保存。该检查不能准确判断所有输入是否已保存，请在更新前完成正在填写的内容。

版本提示针对看板程序。更新使用说明书或技能规则，不会强制让已有 Codex 对话重新读取规则；需要在对应对话中明确要求读取最新版【见全局·山海有径】技能。
